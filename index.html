Playable Ads

Playable HTML5 nhẹ, tải nhanh, tương thích mọi ad network. Mỗi dự án dưới đây đều được build một codebase — xuất đa network, kèm nhiều phiên bản A/B test.

Quy trình làm playable của tôi

  • Phân tích creative — chọn khoảnh khắc gameplay "ăn tiền" nhất để đưa vào 15–30 giây đầu.
  • Prototype nhanh — bản chơi được trong 2–3 ngày để duyệt sớm.
  • Tối ưu — nén tài nguyên, inline toàn bộ asset, đảm bảo dưới 5MB và 60 FPS.
  • Xuất đa network — một lệnh build ra đủ chuẩn MRAID, DAPI, Google HTML5...

Game Developer — Dự án

Các tựa game mobile tôi đã phát triển hoặc tham gia phát triển, từ hyper-casual đến casual puzzle.

Thế mạnh kỹ thuật

  • Gameplay & hệ thống: state machine, object pooling, hệ thống level/progression, save system.
  • Tối ưu: draw call batching, texture atlas, profiling memory & CPU cho thiết bị tầm thấp.
  • LiveOps: remote config, A/B test, event theo mùa, analytics funnel.
  • Monetization: tích hợp rewarded/interstitial ads, IAP, đo lường LTV.
