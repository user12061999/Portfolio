🌐 Publish lên GitHub Pages

Lưu dữ liệu qua GitHub API — sync trên mọi thiết bị, miễn phí. Khi lưu, file data.json trên GitHub sẽ được cập nhật tự động và website public sau ~1 phút.

📋 Hướng dẫn setup lần đầu

Nếu bạn chưa có GitHub repo, làm theo các bước sau:

  1. Tạo tài khoản github.com (nếu chưa có)
  2. Tạo repo mới: nhấn + → New repository → đặt tên portfolio → Public → Create
  3. Upload 3 file: index.html, admin.html, data.json vào repo (kéo thả trực tiếp)
  4. Vào Settings → Pages → Source: main branch → Save → website live sau ~1 phút
  5. Tạo token: Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate → tick repo → Copy token
  6. Dán username, tên repo và token vào form bên trên → Lưu cấu hình

🔄 Chuyển sang hosting riêng sau này

Khi bạn muốn dùng hosting riêng (VPS, shared hosting, Vercel...): chỉ cần copy 3 file HTML/JSON lên server mới. GitHub token vẫn dùng được để lưu data — hoặc bạn có thể thêm một API đơn giản trên server của mình để thay thế.
